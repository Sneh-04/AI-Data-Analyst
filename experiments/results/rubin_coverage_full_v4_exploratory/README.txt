EXPLORATORY (post-hoc, not pre-registered)

This folder contains post-hoc analyses of the existing experiments/results/rubin_coverage_full_v4/raw.csv.gz. No simulation or experiment was rerun. The source v4 results were read only; all generated artifacts are in this folder.

CSV outputs contain an exploratory_label column. Each figure carries the same label. The paired comparison uses matching dataset/trial/mask seeds and resamples whole datasets (2,000 bootstrap replicates, seed 42). MNAR union coverage requires all five recorded delta-SD levels {-1, -0.5, 0, 0.5, 1} to have valid intervals.

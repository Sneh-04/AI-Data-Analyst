# Missing-data imputation benchmark

Datasets: breast_cancer, diabetes, wine.
Targets and MAR predictors: breast_cancer: target `mean radius`, MAR predictor `mean texture`; diabetes: target `bmi`, MAR predictor `bp`; wine: target `alcohol`, MAR predictor `malic_acid`.
Mechanisms: mar, mnar; seeds start at 42; trials per condition: 10.
Configured mask rates: 10%, 20%, 30%, 40%.

Metrics are computed only on artificially masked, originally observed target values. Per-method error CIs are t-based 95% intervals over repeated masks on each fixed dataset; they do not quantify uncertainty across datasets or populations. Runtime is descriptive and has no confidence interval.
